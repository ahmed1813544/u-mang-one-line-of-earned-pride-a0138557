# One Line of Earned Pride

Entry for the [make.fun bounty "One Line of Earned Pride"](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557).

## What it does

`main.py` (stdlib-only Python) writes one line of text — a quiet, earned moment of pride — to `/output/entry.txt` (honouring `MAKEFUN_OUTPUT_DIR` when set).

## Run it

```sh
python3 main.py
```
